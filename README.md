Site interactive pour apprendre les bases de React en utilisant l'API de Pokémon.

Ce que fait l'application :

Affichage dynamique : Elle récupère et affiche une liste de 20 Pokémon avec leurs images (utilisation du fetch).

Favoris : On peut cliquer sur le bouton ("⭐ Favoris") pour ajouter un Pokémon en favori, ce qui met à jour un compteur global en haut de la page.

Détails : Un bouton permet d'afficher ou de cacher les infos (taille, poids) de chaque Pokémon.

Navigation : Un mode "Pokédex" permet de faire défiler tout les Pokémon un par un avec des flèches.
